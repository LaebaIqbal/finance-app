# Finanz-App (Vibecoding-Projekt)

Eine mobile Finanz-App zum Tracken von monatlichen Ausgaben, gebaut mit Flutter/Dart.

## Aktueller Stand

Umgesetzt
Spendings-Seite:

- Budget-Anzeige mit Restbudget + Fortschrittsbalken
- Liste der Ausgaben des aktuellen Monats, kategorisiert
- Hinzufügen neuer Ausgaben
- Diagramm der Ausgaben nach Kategorie (Tortendiagramm)
